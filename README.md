# TransferTime-Z

TOOL移載の **荷つかみ動作／荷おろし動作のサイクルタイム** を自動計算するブラウザツールです。

昇降ストローク・クリープ距離・速度・加減速度・制御遅れなどを入力すると、区間ごとの距離と時間、総移載時間 TC、仕様値に対する合否判定、速度線図、昇降動作のシミュレーション（動画保存つき）をその場で表示します。

- ビルド不要・依存ライブラリなしの静的サイト（HTML + CSS + Vanilla JS）
- 入力を変更すると即座に再計算（`input` イベントで全項目を再計算）
- 表示はすべて日本語

## 使い方

`index.html` をブラウザで開くだけで動作します。

```bash
git clone https://github.com/cozy51/2026-08_calc_transfertime-z.git
cd 2026-08_calc_transfertime-z
# そのまま開く
xdg-open index.html   # macOS は open、Windows は start
```

ローカルサーバー経由で開きたい場合は任意の静的サーバーで配信できます。

```bash
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

GitHub Pages などの静的ホスティングにもそのまま配置できます（サーバー側の処理は一切ありません）。

## 計算ロジック

### 区間時間・距離

計算順は T1 → T2 → S2 → T4 → S4 → S3 → T3 → T5 です。

| 記号 | 式 | 意味 |
| --- | --- | --- |
| T1 | `S1 ÷ V1` | 上端クリープ時間 |
| T2 | `(V2 − V1) ÷ A1` | 加速時間（V1 から加速） |
| S2 | `(V1 + V2) × T2 ÷ 2` | 昇降加速距離 |
| T4 | `(V2 − V3) ÷ A2` | 減速時間（V3 まで減速） |
| S4 | `(V2 + V3) × T4 ÷ 2` | 昇降減速距離 |
| S3 | `SH − (S1 + S2 + S4 + S5)` | 最高速昇降距離 |
| T3 | `S3 ÷ V2` | 最高速昇降時間 |
| T5 | `S5 ÷ V3` | 下端クリープ時間 |

加速は 0 mm/s ではなく上端クリープ速度 V1 から始まり、減速は下端クリープ速度 V3 で終わります（区間の間で軸が停止しないモデル）。

### 合計時間

```
TT = T1 + T2 + T3 + T4 + T5                             （動作時間・方向ごと）
TM = TR(下降) + TT(下降) + TG + TR(上昇) + TT(上昇)      （実移載時間）
TC = TM + TS                                            （総移載時間）
```

TC が仕様値以下なら「合格」、超過すれば「不合格」と判定されます。

### 短ストローク時の扱い（三角速度プロファイル）

ストロークが短く V2 まで到達できない場合は、加速と減速だけで構成される三角プロファイルとして到達可能な最高速度を求め直します（`calculateMotion` の `reachableSpeed`）。到達最高速度はクリープ速度の大きい方（`max(V1, V3)`）を下限とし、V2 を上限とします。この場合 S3 は 0、T3 も 0 になります。

### 入力チェック

- 速度・加減速度（V1・V2・V3・A1・A2）は 0 より大きい値が必要
- その他の項目は 0 以上
- `S1 + S5` が SH を超えるとストローク不足として警告を表示

いずれかに違反すると結果表示はクリアされ、画面上部に警告が出ます。

## 動作シミュレーション

4つのボタン（荷つかみ下降／上昇、荷おろし下降／上昇）で対象動作を選び、「スタート」で実際の動作時間 TT に合わせて再生します。荷物の有無（荷つかみ上昇時・荷おろし下降時は荷物を保持）も図に反映されます。

- **クリープ区間を拡大表示**（既定 OFF）
  クリープ距離はストローク全体に対して極端に短いため、図中では 1〜2 px にしかなりません。ON にすると該当区間を最大 5 倍まで拡大し、同じ倍率だけ再生を遅くします。画面上の見かけの速さは実寸表示と変わらず、再生時間だけが長くなります。経過時間・移動位置・速度は常に実際の値です。
- **自動一時停止条件**
  位置（mm）／時間（s）／速度（mm/s）のいずれか1つを選び、指定値に到達した時点で自動的に一時停止します。
- **動画を保存**
  選択中の動作を先頭から再生しながら Canvas を録画し、動画ファイルとしてダウンロードします。対応ブラウザでは MP4（H.264）、非対応の場合は WebM（VP9／VP8）になります。ファイル名は `TransferTime-Z_<動作名>_<日時>.mp4` 形式です。録画中は入力欄と各操作が無効化されます。

## ファイル構成

```
index.html    画面構造（入力・結果・シミュレーション・速度線図・区間別詳細）
app.js        入力定義、計算ロジック、シミュレーション、速度線図描画、動画書き出し
styles.css    レイアウトとテーマ
favicon.svg   ファビコン
```

`app.js` 冒頭の `motionFields` / `extras` / `sharedDefaults` が入力項目と初期値の定義です。項目や既定値を変更する場合はここを編集すると、入力フォーム・リセット処理の両方に反映されます。

## 動作環境

モダンブラウザ（Chrome / Edge / Safari / Firefox の最新版）を想定しています。動画保存には `MediaRecorder` と `HTMLCanvasElement.captureStream()` が必要で、非対応環境では「動画を保存」ボタンが無効になります。計算・シミュレーション・速度線図はこれらに依存しません。
